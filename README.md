# XIN-YA · พิชิต TOCFL กับ AI 老師 (ตัวต้นแบบ v19)

เว็บฝึกคำศัพท์ TOCFL Band A–B ของ XIN-YA Mandarin — ไฟล์ชุดนี้พร้อมอัปขึ้น GitHub และเปิดบน Vercel ได้ทันที (ช่วง 1)
รายละเอียดทั้งหมดสำหรับ Claude / Cursor อยู่ใน **CLAUDE.md**

## มีอะไรในโฟลเดอร์นี้
| ไฟล์ / โฟลเดอร์ | คืออะไร |
|---|---|

## ขั้นตอนอัปขึ้น GitHub + Vercel
1. **GitHub:** สร้าง repo ใหม่ (เช่น `xinya-tocfl-web`, ตั้งเป็น Private ได้) → กด **uploading an existing file** → ลากไฟล์และโฟลเดอร์ทั้งหมดในโฟลเดอร์นี้ลงไป → Commit
   (ไฟล์ `.gitignore` อาจถูกซ่อนบน Mac — กด `Cmd + Shift + .` เพื่อให้เห็น หรือข้ามไปก็ได้)
2. **Vercel:** Add New → Project → เลือก repo → Framework Preset = **Other** → Deploy (ไม่ต้องตั้ง build command)
3. **โดเมน:** Vercel → Settings → Domains → ใส่ `app.xuantaitechnology.com` → ไปเพิ่ม **CNAME** ตามที่ Vercel บอก ที่ผู้ให้บริการโดเมน
4. เปิดเว็บแล้วลองทุกแท็บ ทั้งบนมือถือและคอม

## ทดลองบนเครื่องตัวเอง
เปิดด้วยดับเบิลคลิกจะโหลดไฟล์ลำดับขีดไม่ได้ (เบราว์เซอร์บล็อก) ให้เปิดผ่านเซิร์ฟเวอร์จำลอง:
```
cd xinya-tocfl-web
python3 -m http.server 8000
```
แล้วเปิด http://localhost:8000

## ข้อจำกัดของตัวต้นแบบ
- **AI 老師** ทำงานเฉพาะตอนเปิดใน Claude — บน Vercel จะขึ้นข้อความว่าใช้ไม่ได้ จนกว่าจะทำ `/api/ask` (ช่วง 3) ส่วนคำตอบคำที่มักสับสนจากไฟล์ใช้ได้ปกติ
- **เข้าสู่ระบบ / Google / Apple** ยังเป็นตัวอย่าง (ไม่มีบัญชีจริง) — ทำจริงในช่วง 2 ด้วย Supabase
- **ความคืบหน้า** เก็บในเบราว์เซอร์เครื่องนั้นเท่านั้น
- **ลิงก์ซื้อหนังสือ** ยังเป็น `https://xuantaitechnology.com/shop/` — แก้ค่า `BOOK_URL` ใน `index.html` เป็นหน้าสินค้าจริง
