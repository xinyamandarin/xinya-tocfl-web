# คู่มือแก้ข้อมูลเว็บ XIN-YA TOCFL (สำหรับทีม)

> **สรุปสั้น:** แก้ใน Google Sheet → ติ๊ก ✅ → เว็บอัปเดตเองทุกคืนตอนตี 3 หรือกดอัปเดตทันทีได้ ไม่ต้องแตะโค้ด

---

## A. ตั้งค่าครั้งแรก (ผู้ดูแลทำครั้งเดียว ใช้เวลาประมาณ 10 นาที)

1. **สร้าง Google Sheet**
   - เปิด Google Drive แล้วอัปไฟล์ `XINYA_TOCFL_data.xlsx`
   - ดับเบิลคลิกไฟล์ → **เปิดด้วย Google ชีต** → เมนู **ไฟล์ → บันทึกเป็น Google ชีต**
   - ใช้ไฟล์ Google ชีตที่ได้ ไม่ใช่ไฟล์ .xlsx เดิม
2. **คัดลอก Sheet ID:** ID คือข้อความยาว ๆ ในลิงก์ระหว่าง `/d/` กับ `/edit`
   ตัวอย่าง: `https://docs.google.com/spreadsheets/d/`**`1AbC…xyz`**`/edit`
3. **เปิดสิทธิ์ให้ระบบอ่านชีตได้** (เลือก 1 วิธี)
   - **ง่าย:** แชร์ → การเข้าถึงทั่วไป → *ทุกคนที่มีลิงก์* → **ผู้มีสิทธิ์อ่าน**
     - คนที่ไม่มีลิงก์จะหาไม่เจอ
     - อย่าโพสต์ลิงก์นี้ที่ไหน
   - **ส่วนตัวกว่า:** สร้าง Service Account ใน Google Cloud
     - แชร์ชีตให้อีเมลของ service account แบบผู้อ่าน
     - ใส่ไฟล์ JSON ของ service account เป็น secret `GOOGLE_SA_JSON`
4. **ใส่ Secret ใน GitHub**
   - ที่ repo `xinya-tocfl-web` ไปที่ **Settings → Secrets and variables → Actions → New repository secret**
   - Name: `SHEET_ID` · Secret: ID จากข้อ 2
5. **ทดสอบ**
   - ไปที่ **Actions → Sync Google Sheet → Run workflow**
   - รอประมาณ 1 นาที แล้วกดเข้าไปดูรายงานผล
6. **ให้ทีมเข้าแก้ชีต:** แชร์ชีตแบบ **ผู้แก้ไข** ให้อีเมลของคนในทีมทีละคน

> 💡 อยากให้ช่อง ✅ เป็นกล่องติ๊ก: เลือกทั้งคอลัมน์ ✅ ขึ้นเว็บ → **แทรก → ช่องทำเครื่องหมาย**

## B. แก้ข้อมูลทุกวัน (ทีม)

| อยากแก้อะไร | แท็บ | คอลัมน์ |
|---|---|---|
| ความหมายคำ (ไทย / อังกฤษ) | คำศัพท์ | ความหมายไทย · ความหมายอังกฤษ |
| พินอินของคำ | คำศัพท์ | พินอิน |
| ประโยคตัวอย่างและคำแปล | คำศัพท์ | ประโยคตัวอย่าง · พินอินประโยค · คำแปลประโยค |
| คำอธิบายคำที่มักสับสน | คำสับสน_กลุ่ม (หลักจำ, จุดที่มักผิด) · คำสับสน_คำ (ความหมาย, วิธีใช้, ประโยค) | |
| ชื่อไทย / หมวดของ 部首 | 部首214 · 部首_บทเรียน | |
| 部首 / พินอิน ของตัวอักษร | ตัวอักษร | |

**ขั้นตอน**
1. แก้ข้อความในช่อง
2. **ผู้ตรวจ** ดูแล้วถูกต้อง → ติ๊ก **✅ ขึ้นเว็บ** ในแถวนั้น
   - ถ้ายังไม่แน่ใจ ให้เอาติ๊กออกก่อน แถวนั้นเว็บจะใช้ข้อมูลเดิมไปก่อน
3. รอรอบตี 3 หรือให้ผู้ดูแลกด **Run workflow** (ข้อ A5) เว็บจะเปลี่ยนในประมาณ 2 นาที
4. เขียนบันทึกถึงกันได้ในช่อง **หมายเหตุผู้ตรวจ** ช่องนี้ไม่ขึ้นเว็บ

> ⚠️ ตอนนี้ทุกแถวติ๊ก ✅ ไว้แล้ว **ถ้าจะแก้แถวไหนแต่ยังไม่ได้ตรวจ ให้เอาติ๊กออกก่อนแก้** แล้วค่อยติ๊กคืนเมื่อตรวจเสร็จ

### ห้ามทำ
- ห้ามแก้หัวตารางแถวแรก โดยเฉพาะคำในวงเล็บ `[thai]` `[ok]`
- ห้ามแก้คอลัมน์รหัส (คอลัมน์สีเทา) ได้แก่ เลขที่ · รหัสกลุ่ม · 部首 · ตัวอักษร
- ห้ามเปลี่ยนชื่อแท็บ

### พินอินประโยค
- เขียน **ทีละคำตามที่ระบบตัดคำ คั่นด้วยเว้นวรรค** เช่น `wǒ shì xuéshēng` (我 / 是 / 學生)
- **แก้ประโยคจีนใหม่:**
  1. ลบช่องพินอินประโยคให้ว่าง
  2. ระบบใส่พินอินอัตโนมัติ และแสดงในรายงานหัวข้อ ⚠️ ควรตรวจ
  3. คัดลอกพินอินจากรายงานมาตรวจ แก้คำที่อ่านผิด (เช่น 還 hái/huán, 了 le/liǎo) แล้ววางกลับในช่อง
- จำนวนคำต้องเท่าเดิม ถ้าไม่เท่า ระบบใช้พินอินเดิมหรือพินอินอัตโนมัติ และเตือนในรายงาน
- ใส่ `?` แทนคำที่ไม่ต้องแสดงพินอินได้

### ตัวย่อ
ช่องตัวย่อและประโยคตัวย่อ **เว้นว่างได้** ระบบแปลงจากตัวเต็มให้ ถ้าแปลงผิดค่อยพิมพ์เอง

### เพิ่มคำใหม่
1. เพิ่มแถวท้ายแท็บคำศัพท์ ใส่ **เลขที่ใหม่ที่ไม่ซ้ำ**
2. กรอกระดับ (N1 N2 A1 A2 B1 B2) ตัวเต็ม พินอิน และความหมายไทย ให้ครบ
3. ติ๊ก ✅

ถ้ามีตัวอักษรที่ไม่เคยมีมาก่อน ระบบจะดึงข้อมูล部首และลำดับขีดให้อัตโนมัติ

### ลบคำ
การลบแถวในชีต **ไม่** ลบออกจากเว็บ (กันพลาด) ถ้าต้องลบจริงให้แจ้งผู้ดูแล

## C. อ่านรายงานผล
เปิด **GitHub → Actions → Sync Google Sheet → รอบล่าสุด** รายงานแบ่งเป็น 4 หัวข้อ:
- **✏️ แก้แล้วขึ้นเว็บ:** แสดงค่าเดิม → ค่าใหม่ ทุกช่องที่เปลี่ยน
- **🆕 เพิ่มใหม่**
- **⏳ ยังไม่ติ๊ก:** แถวที่แก้ในชีตแล้วแต่ยังไม่ขึ้นเว็บ
- **⚠️ ควรตรวจ:** ประโยคใหม่ที่ใช้พินอินอัตโนมัติ, ระดับหรือหมวดผิด, พยางค์พินอินไม่ตรงจำนวนตัวอักษร

**ถ้ารอบนั้นขึ้นกากบาทแดง ❌** แปลว่าข้อมูลผิดร้ายแรง (เช่น หัวตารางหาย ข้อมูลหายเกิน 5% หรือ部首ไม่ครบ 214) ระบบจะ **ไม่อัปเดตเว็บ** เว็บยังใช้ข้อมูลเดิมอยู่ ให้แก้ชีตแล้วกด Run ใหม่

## D. ลำดับขีดมาตรฐานไต้หวัน
1. ทำไฟล์ลำดับขีด 1 ตัวต่อ 1 ไฟล์ รูปแบบ Hanzi Writer `{"strokes":[…],"medians":[…]}`
2. ตั้งชื่อไฟล์เป็น `#U4e4b.json` หรือชื่อตัวอักษรเลย เช่น `之.json` จะรวมหลายไฟล์เป็น .zip ก็ได้
3. ใน GitHub ไปที่โฟลเดอร์ `hw/tw/` → **Add file → Upload files** → ลากไฟล์ลงไป → Commit
4. ระบบตรวจไฟล์และรวมเป็น `hw/tw.json` ให้เอง เว็บอัปเดตในประมาณ 2 นาที
   - ไฟล์ที่ผิดจะแสดงในรายงานหัวข้อ "Merge Taiwan stroke order"

เว็บใช้ไฟล์ใน `hw/tw/` ก่อนเสมอ ถ้าตัวไหนไม่มีจะใช้ลำดับขีดมาตรฐานทั่วไป

> ใช้เว็บกระทรวงศึกษาธิการไต้หวัน (教育部筆順) เป็น **ตัวอ้างอิงด้วยตา** เท่านั้น ห้ามคัดลอกข้อมูลจากเว็บนั้น เพราะสัญญาอนุญาตไม่อนุญาต
